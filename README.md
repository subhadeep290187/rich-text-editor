# rich-text-editor

A lightweight React-based SDK for building rich text editing experiences. This project demonstrates a basic rich text editor implementation with Vite, TypeScript, and React, and can be used as a starting point for integrating editor features into larger applications.

## 🛠️ Tech Stack

- HTML, CSS, JavaScript, React

## 🚀 Features

- **Feature 1:** basic capicity of rich text editor like bold, italic & underline.

## 🏁 Getting Started
- npm run dev
- [localhost:5173](http://localhost:5173/)

### Core Formatting & Layout
* **Typography:** Bold, italic, underline, strikethrough, subscript, and superscript styling.
* **Text Blocks:** Semantic H1–H6 heading structures, paragraphs, and blockquotes.
* **Lists:** Ordered, unordered, and interactive task checklists.
* **Alignment:** Flexible left, center, right, and fully justified text layouts.
* **Colors:** Custom text color highlights and structural background fills.

### Advanced Content Elements
* **Dynamic Tables:** Resizable columns, cell merging/splitting, and quick row/column operations.
* **Media Embeds:** Drag-and-drop file uploads, interactive image resizing, and inline video embeds.
* **Hyperlinks:** Link insertion with support for custom target windows and title tags.
* **Code Blocks:** Syntax highlighting for multiple programming languages with auto-detection.
