# rich-text-editor

A lightweight React-based SDK for building rich text editing experiences. This project demonstrates a basic rich text editor implementation with Vite, TypeScript, and React, and can be used as a starting point for integrating editor features into larger applications.

## 🛠️ Tech Stack

- HTML, CSS, JavaScript, React

## 🚀 Features

- **Feature 1:** basic capicity of rich text editor like bold, italic & underline.

## 🏁 Getting Started
